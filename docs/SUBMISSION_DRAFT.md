DeliveryReview: frozen evidence and independent validator assessment

Notes / Description (under the form's 1,000-character limit):

Standalone GenLayer contract for reviewing a frozen text deliverable against immutable requirements. It enforces assigned-worker submission, participant-only assessment, bounded inputs, exact evidence quotations, and a single recorded assessment. Validators independently repeat the assessment and compare requirement IDs, decisions and bases; aggregate met/unmet/insufficient-evidence outcomes are derived deterministically. Prepared with AI assistance. Validation: 55 SDK direct-mode tests passed with mocked model responses; GenVM lint and SDK validation passed. A live Studio deployment, submission and assessment all finalized successfully. The synthetic example returned met for two command-presence requirements after a leader rotation. This is a text-evidence prototype, not audited software or proof that delivered code runs. No point award or airdrop eligibility is claimed.
